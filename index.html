FindMeTricycle

A full-stack transportation booking and management system built to address local transportation challenges in Guiuan, Eastern Samar, Philippines. It connects passengers with available tricycle drivers through a mobile app, making local transport more organized, accessible, and transparent.

Problem addressed: Limited access to organized tricycle booking, no real-time transportation visibility, and manual ride coordination.

Key Features

  • Passenger and driver mobile interfaces built with Flutter and Dart
  • Real-time booking, driver location tracking, and ride status updates via Socket.IO
  • Secure authentication with email OTP verification and role-based access
  • Driver application website with document submission and identity verification
  • Admin dashboard for driver verification, bookings, fares, and users
  • Geofencing to manage transportation service boundaries
  • Ride history, passenger ratings, notifications, and safety reporting
  • Cloud deployment for frontend, backend services, and database

TowerNet: Packet-Protocol

An interactive browser-based tower defense game that makes computer networking concepts easier to learn through gamified play. Players learn network defense, data packet transmission, server protection, and the seven layers of the OSI model through strategic challenges.

Problem addressed: Abstract networking concepts are hard to grasp through traditional learning methods.
Goal: Make networking education more interactive, engaging, and easier to understand.

Key Features

  • Browser-based tower defense game built with HTML5, CSS3, and JavaScript
  • The seven OSI layers integrated into the gameplay mechanics
  • Ten progressive waves with increasing difficulty
  • Network-themed towers, packet-based enemies, and server protection
  • Interactive server connection system using IP address input
  • Real-time gameplay logs, network status indicators, and visual feedback
  • Tutorials, sound effects, animations, and fullscreen mode
  • Responsive layouts and mobile compatibility improvements
